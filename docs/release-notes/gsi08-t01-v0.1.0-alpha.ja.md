**研究・実験用アルファ版**

GSI-08 T01の初回研究用アルファ版を公開するためのリリース文です。

本リリースは、複数のエージェントによる操作が共有リソースへ与える影響と、安全な受付制御の考え方を検証するための、独立したPythonシミュレータです。

特定のAIモデル、開発企業、クラウドサービスへの依存を前提としない研究用実装として提供します。

## 主な実装内容

以下は公開者が提示した公開候補の実装内容です。

- 共有リソースの複合的な安全性評価
- 計画・証拠情報の整合性確認
- STOP・DENY・HOLD・ALLOWの判定処理
- 単一プロセス内の原子的な受付とリソース予約
- 模擬承認と権限世代の検証
- 重複操作の防止
- 監査履歴と受付レシートの整合性検証
- FH01による確定FAILの優先順位修正
- 並行受付を含む300試行の検証用試験

## 既知の問題と制限事項

本アルファ版には、以下の未解決・未確認事項があります。

- **監査履歴（AUDIT02）：** 監査破損を検出しても、その後の正常な承認済み操作の受付が自動的に停止されない
- **証拠情報：** 不明な証拠情報に対する意味的な整合性確認に制限がある
- **STOP解除・復旧：** 独立した認証・承認を伴う権限管理が未完成
- **模擬承認機構：** 承認情報の所有権や並行処理に関する保証が限定的
- **検証範囲：** 一部の内部試験では実際の受付判定まで確認していない
- **性能：** 大規模入力や長期間実行時の性能・処理時間は保証されていない

これらは既知の制限事項として継続管理します。未解決の問題を修正済みとして扱うことはありません。
